# 13 — Build Handoff Checklist

## Before coding
- [ ] Read all relevant docs.
- [ ] Inspect repository and identify the real entry point.
- [ ] Run baseline and record commands/results.
- [ ] Create a checkpoint/branch.
- [ ] List verified facts, assumptions, and blockers.
- [ ] Confirm no secret values are present in files or output.

## Before each phase
- [ ] Define the scope and acceptance criteria.
- [ ] Identify the smallest set of files to change.
- [ ] Confirm the change does not silently remove existing behaviour.
- [ ] Identify privacy, accessibility, and safety implications.

## After each phase
- [ ] Run relevant tests.
- [ ] Run build/typecheck/lint if available.
- [ ] Inspect diff.
- [ ] Update docs and traceability.
- [ ] Record test results and limitations.
- [ ] Leave the project in a working state.

## Before final demo
- [ ] Fresh start works without paid API credentials.
- [ ] Guest mode works.
- [ ] Voice, text, and manual paths behave as documented.
- [ ] Recommendation reason is explainable.
- [ ] Session playback controls work.
- [ ] Feedback loop is demonstrable.
- [ ] Safety and privacy disclosures are visible where relevant.
- [ ] Simulated sensor/device actions are labelled.
- [ ] No false claims about Alexa+, physical devices, or remote storage.
- [ ] Current official hackathon rules and deadline are rechecked.
- [ ] Demo has been rehearsed twice from a clean start.
- [ ] Human reviewed final repository, video, and submission fields.
